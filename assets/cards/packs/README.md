# Card face packs

Unzip each pack exported by `/?asset-import` into its own folder here:

    assets/cards/packs/<pack-name>/manifest.json
    assets/cards/packs/<pack-name>/cards/*.png

Then restart `npm run dev:web` or rebuild. Rights: FAN_MADE_NON_COMMERCIAL (ADR-004; DMCA/takedown: scurvycatt@gmail.com). Packs are committed to git because the Cloudflare build bundles them.
